プライバシーポリシー

最終更新日：2026年11月1日

「トイレマップ」（以下「本アプリ」）は、ユーザーのプライバシーを尊重し、 個人情報および関連する情報を適切に取り扱います。

1. 取り扱う情報

(1) 位置情報

本アプリでは、現在地周辺のトイレを地図上で確認するため、 端末の位置情報を利用します。

位置情報は、現在地の表示、周辺施設の検索、地図上での位置確認等のために利用します。 現在地の移動履歴を保存することを目的として利用するものではありません。

ただし、ユーザーが新しい施設を登録した場合は、 登録時の施設の緯度・経度を施設情報として Firebase / Cloud Firestoreに保存します。 登録された施設の位置情報は、他の利用者にも公開されます。

(2) 施設・トイレ情報

ユーザーが本アプリを通じて施設やトイレの情報を登録した場合、 以下のような情報を取り扱います。

  • 施設名
  • 施設の位置情報（緯度・経度）
  • トイレの種類
  • 設備情報
  • 利用時間等
  • 評価その他の入力内容
  • 投稿者を識別するための内部ID（UID）

これらの情報は、本アプリ上でトイレ情報を表示・提供するため、 また施設情報の管理および不正利用の防止のために利用します。 登録された施設情報は、他の利用者にも公開されます。

(3) 問題報告

ユーザーが施設情報について問題を報告した場合、 以下の情報を取り扱います。

  • 対象施設を識別するための情報
  • 報告理由
  • ユーザーが入力したコメント（最大200文字）
  • 報告日時
  • 報告者を識別するための内部ID（UID）

これらの情報は、施設情報の確認、修正、管理および 重複・誤情報等への対応のために利用します。 問題報告の内容は、一般利用者には公開せず、 運営者による確認・管理に利用します。

(4) お気に入り

お気に入り登録した施設の情報は、本アプリの利便性を提供するため、 ユーザーの端末内に保存されます。

2. ユーザー登録について

本アプリでは、氏名、メールアドレス、電話番号等を入力する 通常のユーザー登録やログイン操作を必要としません。

ただし、施設登録および問題報告の権限管理、不正利用の防止のため、 Firebase Authenticationの匿名認証を利用しています。 アプリの利用に際して内部用の識別子（UID）が自動的に発行されます。

このUIDは、施設の投稿者情報や問題報告の送信者情報と関連付けて Firebase / Cloud Firestoreに保存されます。 UIDはアプリ内部の識別・管理に利用し、 氏名、メールアドレス、電話番号等のプロフィール情報を UIDに登録するものではありません。

3. 第三者サービスについて

本アプリでは、以下の第三者サービスを利用しています。

  • Google Maps Platform
  • Firebase Authentication
  • Firebase / Cloud Firestore

これらのサービスでは、地図表示、認証、データ保存等の サービス提供に必要な情報が取り扱われる場合があります。

各サービスにおける情報の取り扱いについては、 各提供事業者のプライバシーポリシー等もご確認ください。

  • Google プライバシーポリシー
  • Firebase プライバシーとセキュリティ

4. 情報の利用目的

  • 地図上でトイレ情報を表示するため
  • 現在地周辺の施設を検索するため
  • 施設情報や設備情報を提供するため
  • ユーザーが登録した情報を保存・表示するため
  • 問題報告を確認し、施設情報を管理するため
  • 匿名認証による投稿者の識別・権限管理のため
  • 不正利用の防止および本アプリの安全性を維持するため
  • お気に入り機能を提供するため
  • 本アプリの機能を維持・改善するため

5. 情報の第三者提供

本アプリ運営者は、法令に基づく場合を除き、 取得した情報を本人の同意なく第三者へ提供することを 原則として行いません。

ただし、本アプリの提供に必要なGoogle Maps Platformや Firebase等の第三者サービスについては、 各サービス提供者の仕組みに従って情報が取り扱われる場合があります。

また、ユーザーが登録した施設情報は、 本アプリの機能上、他の利用者に公開されます。

6. 情報の保存

施設情報、トイレ情報、投稿者を識別するUID、 問題報告および報告者を識別するUID等、 本アプリの運営に必要な情報はFirebase / Cloud Firestoreに保存されます。

Firebase Authenticationでは、匿名認証に必要な内部識別情報が管理されます。

お気に入り情報はユーザーの端末内に保存されます。

7. ユーザーによる情報の修正・削除等

利用者は、新しいトイレ施設の情報を本アプリに登録することができます。 登録された施設情報は、他の利用者にも公開されます。

登録済み施設の編集・削除は一般利用者にはできません。 情報の誤り、重複、施設の閉鎖等を発見した場合は、 本アプリ内の問題報告機能またはサポート窓口からご連絡ください。 運営者が内容を確認し、必要に応じて修正・削除等の対応を行います。

本アプリの利用に伴う情報の取り扱いに関するお問い合わせは、 サポート窓口までご連絡ください。

8. プライバシーポリシーの変更

本ポリシーの内容は、法令や本アプリの仕様変更等に応じて 変更する場合があります。

変更後のプライバシーポリシーは、公開ページ上で掲載します。

9. お問い合わせ

本アプリに関するお問い合わせ、施設情報に関するご連絡、 不具合の報告、ご意見・ご要望については、 本アプリのサポート窓口をご利用ください。
