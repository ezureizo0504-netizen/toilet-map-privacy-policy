プライバシーポリシー

最終更新日：2026年9月28日

「トイレマップ」（以下「本アプリ」）は、ユーザーのプライバシーを尊重し、 個人情報および関連する情報を適切に取り扱います。

1. 取り扱う情報

(1) 位置情報

本アプリでは、現在地周辺のトイレを地図上で確認するため、 端末の位置情報を利用します。

位置情報は、現在地の表示や地図上での位置確認等のために利用します。

本アプリでは、ユーザーの現在地そのものを本アプリのデータベースに 保存することを目的としていません。

(2) 施設・トイレ情報

ユーザーが本アプリを通じて施設やトイレの情報を登録した場合、 以下のような情報を取り扱います。

  • 施設名
  • 施設の位置情報
  • トイレの種類
  • 設備情報
  • 利用時間等
  • 評価その他の入力内容

これらの情報は、本アプリ上でトイレ情報を表示・提供するために利用します。

(3) 問題報告

ユーザーが施設情報について問題を報告した場合、以下の情報を取り扱います。

  • 対象施設を識別するための情報
  • 報告理由
  • ユーザーが入力したコメント（最大200文字）
  • 報告日時

これらの情報は、施設情報の確認、修正、管理および重複・誤情報等への対応のために利用します。

(4) お気に入り

お気に入り登録した施設の情報は、本アプリの利便性を提供するため、 ユーザーの端末内に保存されます。

2. ユーザー登録について

本アプリでは、氏名、メールアドレス、電話番号等を用いたユーザーアカウントの登録を必須としていません。

3. 第三者サービスについて

本アプリでは、以下の第三者サービスを利用しています。

  • Google Maps Platform
  • Firebase / Cloud Firestore

これらのサービスでは、サービス提供に必要な情報が取り扱われる場合があります。

各サービスにおける情報の取り扱いについては、 各提供事業者のプライバシーポリシー等もご確認ください。

4. 情報の利用目的

  • 地図上でトイレ情報を表示するため
  • 施設情報や設備情報を提供するため
  • ユーザーが登録した情報を保存・表示するため
  • 問題報告を確認し、施設情報を管理するため
  • お気に入り機能を提供するため
  • 本アプリの安全性および機能を維持・改善するため

5. 情報の第三者提供

本アプリ運営者は、法令に基づく場合を除き、 取得した情報を本人の同意なく第三者へ提供することを原則として行いません。

ただし、本アプリの提供に必要な第三者サービスについては、 各サービス提供者の仕組みに従って情報が取り扱われる場合があります。

6. 情報の保存

施設情報、トイレ情報、評価、問題報告等、本アプリの運営に必要な情報は Firebase / Cloud Firestoreに保存されます。

お気に入り情報はユーザーの端末内に保存されます。

7. ユーザーによる情報の削除等

本アプリではユーザーアカウントを設けていないため、 アカウント情報の削除手続きはありません。

利用者は、新しいトイレ施設の情報を本アプリに登録することができます。 登録された施設情報は、他の利用者にも公開されます。 なお、登録済み施設の編集・削除は一般利用者にはできません。 情報の誤り、重複、施設の閉鎖等を発見した場合は、 本アプリ内の報告機能またはサポート窓口からご連絡ください。 運営者が内容を確認し、必要に応じて修正・削除等の対応を行います。

8. プライバシーポリシーの変更

本ポリシーの内容は、法令や本アプリの仕様変更等に応じて変更する場合があります。

変更後のプライバシーポリシーは、公開ページ上で掲載します。

9. お問い合わせ

本アプリに関するお問い合わせ、施設情報に関するご連絡、 不具合の報告、ご意見・ご要望については、本アプリのサポート窓口をご利用ください。

個別の連絡先については、公開しているサポート窓口に記載された方法をご利用ください。
